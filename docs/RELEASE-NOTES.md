Hub Tool 0.3.4: ripristino rapido delle impostazioni della videocamera.

- Pulsante nella scheda della videocamera per applicare i valori predefiniti forniti dal driver a tutti i controlli supportati.
- Rilettura immediata di slider e modalità automatiche; eventuali proprietà rifiutate vengono indicate senza interrompere l'intero reset.
- Rimane incluso il controllo dell'eco microfono/sidetone con fallback sul volume per il dispositivo Fifine.
- `HubTool.exe` resta disponibile direttamente nella cartella principale e non richiede un'installazione separata di .NET.

Build e controlli automatici passati. L'EXE non è firmato Authenticode; i checksum SHA-256 sono inclusi. Consulta README per i limiti dei driver.
